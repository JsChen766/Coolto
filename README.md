## ✨ Coolto 是什么？

**Coolto（库投）** 是一款面向求职者的 AI 职业工作台。它帮助用户整理真实经历、理解岗位要求、分析匹配度，并基于可追溯的事实生成针对性简历。

```text
经历素材  →  JD 理解  →  匹配分析  →  针对性简历  →  投递管理
```

我们希望 AI 不只是“帮你写得更漂亮”，而是帮助你更准确地发现、组织和表达自己真正做过的事情。

## 🧭 产品原则

- **事实优先**：简历内容必须有用户素材作为依据，不凭空编造经历。
- **用户掌控**：关键写入、修改与投递动作由用户确认。
- **隐私克制**：只收集完成产品功能所必需的数据。
- **长期主义**：先解决真实求职问题，再追求功能数量。
